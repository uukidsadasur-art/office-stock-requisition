# ระบบตัดเบิกของใช้สำนักงานและแม่บ้าน (Office & Housekeeper Inventory Requisition System)

เว็บแอปพลิเคชันสำหรับการเบิกของใช้สำนักงานและอุปกรณ์แม่บ้าน พร้อมระบบตัดสต็อกอัตโนมัติ บันทึกชื่อผู้เบิก วันที่และเวลาอัตโนมัติ เมนูเติมสต็อกสำหรับผู้ดูแล (Admin) และหน้าสรุปภาพรวมรายเดือน เชื่อมต่อกับ Google Spreadsheet

## 📋 คุณสมบัติเด่นของระบบ

1. **หน้าเบิกของ (Requisition System):**
   - แบ่งหมวดหมู่ 4 แผนก/สาขา ตาม Google Sheet อย่างชัดเจน:
     - 🏢 **อุปกรณ์-เครื่องเขียน LC (หลักชัย)**
     - 🏢 **อุปกรณ์-เครื่องเขียน NLL (หนองละลอก)**
     - 🏢 **อุปกรณ์-เครื่องเขียน WC (วังจันทร์)**
     - 🧹 **อุปกรณ์แม่บ้าน (ทำความสะอาด)**
   - ค้นหารายการสินค้าและตัวกรองสถานะสต็อก (พร้อมเบิก, ใกล้หมด, หมดสต็อก)
   - ปรับจำนวนที่ต้องการเบิก ตรวจสอบไม่ให้เบิกเกินจำนวนคงเหลือในคลัง
   - บันทึกชื่อผู้เบิก พร้อมปุ่มเลือกชื่อที่ใช้บ่อย
   - บันทึก **วันและเวลาอัตโนมัติแบบ Real-time** (ตรงตามเวลาจริง)
   - ตัดยอดสต็อกทันที พร้อมออกสลิปสรุปการทำรายการ

2. **เมนูสำหรับผู้ดูแลสต็อก (Admin Restock):**
   - เติมของเพิ่มเข้าสต็อกได้สะดวกรวดเร็ว (ปุ่มด่วน +1, +5, +10 หรือระบุจำนวนตามต้องการ)
   - ปรับปรุงจำนวนสต็อกสินค้าในแต่ละสาขา
   - เพิ่มรายการวัสดุ/อุปกรณ์ใหม่เข้าสู่คลัง
   - บันทึกประวัติการเติมสต็อก (Restock Log)

3. **หน้าสรุปรายเดือนและภาพรวม (Monthly Summary & Analytics):**
   - ตัวเลือกเดือน/ปี ดูสถิติย้อนหลังและภาพรวมทั้งหมด
   - บัตรสรุปตัวชี้วัด (KPIs): ยอดเบิกรวม, จำนวนครั้งที่เบิก, จำนวนผู้เบิก, และรายการที่ต้องสั่งซื้อด่วน
   - กราฟวงกลม (Doughnut Chart) เปรียบเทียบสัดส่วนการเบิกของแต่ละสาขา
   - จัดอันดับ 5 รายการที่มีการเบิกใช้บ่อยที่สุดประจำเดือน
   - ตารางประวัติการเบิก (Requisition Log) ค้นหาและกรองได้
   - **ปุ่มส่งออกรายงานเป็น Excel/CSV (รองรับภาษาไทย UTF-8 BOM)** สำหรับส่งรายงานผู้บริหาร

4. **การเชื่อมต่อกับ Google Sheets:**
   - ฐานข้อมูล: [Google Spreadsheet](https://docs.google.com/spreadsheets/d/1FFbHvRj_jlG-o4U9uI1UnMz0MCNUFHuV-eMzKsA5UKw/edit?usp=sharing)
   - แผ่นงานหลัก 4 Sheet: `อปก.คข.LC `, `อปก.คข.NLL`, `อปก.คข.WC`, `อปก.แม่บ้าน ต.ค.`
   - สร้างชีตบันทึกประวัติอัตโนมัติ: `ประวัติการเบิก` และ `ประวัติการเติมสต็อก`
   - ทำงานได้ทั้งแบบ Offline (บันทึกในเครื่องทันที) และ Online สองทางผ่าน Google Apps Script

## 🚀 วิธีติดตั้งและเชื่อมต่อ Google Apps Script เข้ากับ Google Sheets

ทำเพียงครั้งเดียว เพื่อให้หน้าเว็บส่งข้อมูลไปอัปเดตสต็อกที่ Google Sheets โดยตรง:

1. เปิด [Google Sheets ของคุณ](https://docs.google.com/spreadsheets/d/1FFbHvRj_jlG-o4U9uI1UnMz0MCNUFHuV-eMzKsA5UKw/edit?usp=sharing)
2. ไปที่เมนูด้านบนเลือก **ส่วนขยาย (Extensions) > Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้วคัดลอกโค้ดจากไฟล์ `Code.gs` ในโปรเจกต์นี้ไปวางแทนที่
4. กดบันทึก (รูปแผ่นดิสก์ 💾)
5. กดปุ่มสีน้ำเงินมุมขวาบน **ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)**
6. เลือกประเภท: **เว็บแอป (Web app)**
   - คำอธิบาย: `Office Stock API`
   - ดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)** *(สำคัญมาก เพื่อให้หน้าเว็บส่งข้อมูลเข้าได้)*
7. กด **ทำให้ใช้งานได้ (Deploy)** และให้สิทธิ์เข้าถึง (Authorize access)
8. คัดลอก **URL ของเว็บแอป (Web App URL)** ที่ได้ (ขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)
9. เปิดหน้าเว็บแอพ เข้าเมนู **ตั้งค่า (ไอคอนรูปฟันเฟือง ⚙️)** นำ URL ไปวางแล้วกด **บันทึกการตั้งค่า**

## 🌐 โครงสร้างไฟล์ในโปรเจกต์

- `index.html` : หน้าเว็บแอพพลิเคชันหลัก (Responsive รองรับทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์)
- `app.js` : ระบบคำนวณตัดสต็อก ตะกร้าเบิก รายงานรายเดือน และการเชื่อมต่อ Google Sheets API
- `data.js` : ข้อมูลสินค้าเริ่มต้นทั้ง 111 รายการจาก Google Sheets ทั้ง 4 สาขา
- `Code.gs` : โค้ด Google Apps Script Backend สำหรับติดตั้งบน Google Sheets
